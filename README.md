## Develop
```bash
npm install
npm run dev      # http://localhost:4321/abdulsamad/
npm run build
```
- `src/data/profile.ts` holds all content in English and Arabic.
- `tools/cv/cv.html` renders `public/Abdul-Samad-Hassan-CV.pdf`.
- `tools/reel/` renders the intro video (`intro.html` + `render.mjs`) and its synthesised music (`music.mjs`).
